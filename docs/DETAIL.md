# Quota badge

A single reading of the current model's balance or usage window, in the composer
tool row, immediately left of the model selector.

It follows the session's model. DeepSeek Account shows the wallet; the DeepSeek
API shows that key's balance; any provider you describe with a template can show
a balance path or used/limit window pairs as remaining percentages.

Hover (or focus) the reading for the provider name, every value, and the update
time; click to refresh. Settings → Quota badge edits the refresh interval, the
used/left display, and the provider templates, with a real Test request.
